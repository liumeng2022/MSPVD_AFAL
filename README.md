# MSPVD_AFAL
Data and Results

##  Appendix A (data.xlsx)
Detailed information on the assembly data is presented in Appendix A, including the information on assembly tasks (predecessors, worker requirements, skill requirements, standard processing times and workspaces), assembly workspace capacities, and assembly workers (skill certificates and skill levels).

The information on assembly tasks is presented in Table A.1. The “Task” column gives the serial number of tasks. The “Predecessors” column presents the tasks that must be finished before the current task starts. The “NW” refers to the number of workers required by the current task. The “Skill requirement” column gives the skill certificate required for the current task, where the numbers 1 to 4 refer to aircraft assembly mechanical certificate, structural certificate, avionics certificate, and insulation certificate, respectively. The “SPT” refers to the standard processing time (in hour). The “Workspace” column shows which workspace the current task is located.
Table A.2 presents the capacity of each assembly workspace. The “Workspace” column gives the serial number of workspaces. 
Moreover, Table A.3 presents the information of assembly workers, including their skill certificates and skill levels. The “Worker” column gives the serial number of workers.

##  Appendix B (results.xlsx)
Appendix B shows the detailed worker assignments and task schedules of both cases. 

Table B.1 and Table B.2 present the scheduling results for Case 1 and Case 2, respectively. The “Task” column gives the serial number of tasks. The “Assigned workers” column presents the assigned workers for the current task. The “Start time” column and “Finish time” column show the schedules of the current task and assigned workers. The “SPT” refers to the standard processing time (in hour). The “APT” refers to the actual processing time (in hour).
